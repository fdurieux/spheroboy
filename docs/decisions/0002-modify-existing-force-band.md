# 0002: Modify the existing Sphero Force Band

Status: Accepted  
Date: 2026-10-19

## Context

The project explores turning the Sphero Force Band into a programmable wrist computer. The imported conversation suggested preserving the original set and obtaining another Force Band because of possible collector value. That was advice rather than an owner decision.

## Decision

The owner explicitly stated: “I will modify my Force bank”. In the context of the preceding clarification, this selects the owner's existing **Sphero Force Band** as the hardware to modify. A second Force Band is not a prerequisite.

## Consequences

The target is recorded as [SB-FB-001](../hardware/force-band-01.md). Keeping that Force Band in original collector condition is not a project requirement. Determine original-firmware backup feasibility during the existing debug-access task. The board pinout, protection state, and an actual programming procedure still require investigation; this decision does not establish those technical facts or record any physical modification as performed.
